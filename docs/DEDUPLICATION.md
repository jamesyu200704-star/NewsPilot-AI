# 去重与独立来源

URL 规范化会统一域名大小写、移动版域名和尾部斜杠，删除 fragment、`utm_*`、`spm`、`fbclid` 等跟踪参数，同时保留影响内容的查询参数。

去重按以下信号执行：

1. 规范化 URL 或正文哈希相同：精确重复。
2. 标题/短摘要二元字符相似度达到阈值：近重复。
3. `转载自`、来源字段、显式原稿 ID：转载关系。

重复来源进入同一 `independenceGroupId`。五个转载 URL 仍只算一个独立来源组。无法确定原始出处时保存 `origin_unresolved`，不会只因发布时间更早就宣布它是原稿。

当前实现是适合本地项目的轻量确定性算法，不是法证级文章溯源；标题相似但独立采写的报道仍可能需要用户纠正。
