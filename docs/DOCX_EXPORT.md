# DOCX 与完整提交包导出

导出中心提供九类核心文件：报道策划案、信源地图、分信源采访提纲、执行计划、证据矩阵、报道提纲、作业自查、采访总结和完整提交包。

DOCX 使用标准 OOXML 标题、正文、表格与分页，不要求安装专用字体。文件名会移除 Windows 非法字符。

完整 ZIP 固定包含：

```text
project.json
reporting-plan.md
interview-guide.docx
evidence-matrix.csv
outline.docx
README.txt
```

它不包含音频、完整转写、网页全文、私密联系方式、匿名真实身份、私密/off-record 笔记、未确认引语、本地路径、环境变量、API Key 或模型文件。

导出前必须显式勾选六项隐私确认。课程提交模式存在 blocking 项时，界面不会生成完整提交包。
