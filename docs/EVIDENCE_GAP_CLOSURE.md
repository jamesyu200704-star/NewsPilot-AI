# 证据缺口关闭

P2 显式管理十二类缺口：原始文件、当事方回应、对立观点、数据、独立佐证、时间线、范围不一致、数字冲突、信源不可达、引语未确认、匿名信源风险和归因未确认。

状态为 `open / in_progress / resolved / accepted_risk / dropped`。每项必须绑定主张或信源、说明缺什么、下一步动作和完成条件。

- `resolved`：记录用什么材料或采访解决。
- `accepted_risk`：明确风险和仍可接受的原因。
- `dropped`：说明删除相关主张、引语或报道方向。

系统不会静默关闭缺口，也不会在支持与反驳并存时自动裁决。
