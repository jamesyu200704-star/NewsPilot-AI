# 证据领域模型

P1 的四个核心实体不能混用：

- `Claim`：需要核实的具体说法，包含类型、重要性、范围、来源和状态。
- `SourceRecord`：网页、文件、采访材料或线索的来源元数据。
- `EvidenceItem`：来源中的短片段，包含页码/段落/小节定位、与主张的关系和直接性。
- `ClaimEvidenceMatrixRow`：规则引擎基于已确认片段生成的核实状态与剩余任务。

用户输入“很多学生都用 AI 作弊”会成为 `allegation`，而不是事实。系统生成建议和工作假设也不能自动升级为事实。

来源和证据分离的原因：一篇文件可能同时支持一个主张、反驳另一个主张，并包含纯背景段落。整篇来源不能笼统证明结论。

证据工作区使用 `schemaVersion: 1`；本地项目数据升级到 `dataVersion: 2`，导入 v1 项目时自动添加空证据工作区。JSON 导出包含主张、来源、证据、矩阵、冲突、检索计划和上传材料元数据，不包含上传文件全文或网页全文。
