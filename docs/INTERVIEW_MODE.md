# 采访模式

采访模式同时适配桌面和手机，只突出对象、目的、当前问题、下一题、快速笔记、同意与进度。

## 开始前

- 必须确认采访材料能否使用。
- 必须确认实名、匿名、background 或 off-record 归因边界。
- 录音许可可以是“不允许”，但不能默认为允许。

## 快速记录

支持事实陈述、直接引语、转述、矛盾、追问、新线索和未回答。笔记初始为“待复核”；私密和 off-record 可单独标记。

## 结束与复盘

“结束采访”只进入 `review_required`，不能直接完成。复盘需要列出已确认要点、新线索、未回答问题、冲突、候选引语、下一位信源和跟进任务。完成后，受访者说法仍是归因陈述而非已核实事实。

NewsPilot 不录音、不自动拨号、不生成受访者答案。
