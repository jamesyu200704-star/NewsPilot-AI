# P2 当前限制

- NewsPilot 不发送联系消息、不打电话、不录音、不创建云账号，也不替用户完成真实采访。
- 本地 Whisper 需要用户自行运行兼容 OpenAI transcription API 的回环服务；公开静态部署不可用。
- 自动转写和说话人分段可能出错，必须人工校正。
- 轻量问题风险规则会有漏报或误报，不能替代新闻伦理判断。
- 采访陈述不会自动验证；独立性、匿名必要性、background 使用和冲突解决仍需记者/编辑判断。
- DOCX 生成不保证完全匹配每门课程的自定义模板，提交前应打开检查。
- 浏览器存储没有账号、云同步、跨设备恢复或团队权限；私密备份由用户自行安全保存。
- P2 的 20 个评测项目是离线合成数据，只验证工作流和安全门槛，不代表真实采访质量或用户效果。
- 当前不生成完整新闻稿、不自动发布、不管理媒体 CRM，也不提供多人协作编辑。
