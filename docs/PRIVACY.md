# 隐私说明

默认 Mock 模式下，报道任务、项目、手动文本、上传材料、证据片段和评测内容保存在当前设备的当前浏览器。清除站点数据、更换浏览器或使用无痕窗口可能导致数据丢失，请使用版本化 JSON 备份。

启用不同能力时的数据去向：

- Manual / Mock：不发出搜索网络请求。
- SearXNG：用户主动执行的检索词发送到配置的 SearXNG 服务；网页 URL 发送到 NewsPilot 受控后端获取。
- Ollama/Qwen：任务可能发送到配置的本地或远程模型地址。
- OpenAI：任务发送到 OpenAI API；密钥只在服务端。
- 本地材料：当前版本只在浏览器解析，不上传第三方模型。

不要导入未获授权的采访录音、身份证明、联系方式、敏感健康信息或可能伤害受访者的原始材料。导出前检查文件中的姓名、学号、电话、邮箱、精确住址和元数据。

本项目没有账号、云同步、服务端数据库或删除请求流程。线上部署者必须另行提供隐私政策、日志保留规则、访问控制和数据删除机制。
