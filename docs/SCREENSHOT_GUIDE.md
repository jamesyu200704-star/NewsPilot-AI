# 项目截图指南

截图统一使用浏览器本地 Mock，不启动外部 Provider，也不填写或展示任何 API Key。开发者设置保持折叠。建议使用 Chromium 系浏览器、100% 缩放和 `1440 × 900` 视口；三张截图保持相同视口、主题与窗口尺寸。

最终 PNG 文件直接放在 `docs/`：

- `homepage.png`
- `result.png`
- `export.png`

## homepage.png

展示应用首页与“课程作业模式”初始状态：主标题、四步工作流和任务表单均清晰可见，表单使用无个人指向的演示文字，不显示生成结果。避免展开开发者设置，让截图突出学生任务而非模型配置。

## result.png

使用虚构且不涉及个人信息的主题生成方案，例如“大学生使用生成式 AI 完成课程作业”。优先截图第二步的 Verdict、推荐角度和可行性评分；补充截图可展示第三步信源地图与采访问题，或第四步证据矩阵。避免截断关键卡片标题和操作按钮。

## export.png

在第四步“核查提交”展示新的“资料与证据工作台”。建议画面同时包含 C-001 待核实主张、带明确“模拟”标签的来源卡、证据矩阵和“导出带引用策划案”入口；不得把模拟卡截图成真实检索结果。点击导出后，如浏览器显示下载完成提示，可一并保留，但不得露出本机用户名、下载目录或其他本地路径。

## 信息安全要求

- 不得出现真实 API Key、Token、密码、`.env` 内容或部署平台 Secret。
- 不得出现真实姓名、头像、电话、身份证号、学号、邮箱、地址或聊天记录。
- 不得出现本机用户名、绝对路径、浏览器账号、书签栏、扩展信息或通知内容。
- 截图前关闭开发者工具、密码管理器提示和无关标签页。
- 演示数据统一使用虚构主题；生成结果只作为策划示例，不表示真实采访或事实结论。
