# 项目截图指南

截图统一使用浏览器本地 Mock 模式，不启动 OpenAI Provider，也不填写或展示任何 API Key。建议使用 Chromium 系浏览器、100% 缩放和 `1440 × 900` 视口；三张截图保持相同视口、主题与窗口尺寸。

最终 PNG 文件直接放在 `docs/`：

- `homepage.png`
- `result.png`
- `export.png`

## homepage.png

展示应用首页的初始状态：页面标题、功能说明和完整输入表单均在视口内，表单保持空白或使用无个人指向的演示文字，不显示生成结果。应让默认 Mock 模式提示清晰可见。

## result.png

使用虚构且不涉及个人信息的主题生成方案，例如“校园夜间照明改造”。截图应覆盖结果标题、Mock 模式标识，以及人物、制度、数据趋势三条报道角度的主要内容；避免截断关键卡片标题和操作按钮。

## export.png

在生成完整方案后展示导出场景。截图应同时包含“导出 Markdown”操作入口与已生成结果；点击导出后，如浏览器显示下载完成提示，可一并保留，但不得露出本机用户名、下载目录或其他本地路径。

## 信息安全要求

- 不得出现真实 API Key、Token、密码、`.env` 内容或部署平台 Secret。
- 不得出现真实姓名、头像、电话、身份证号、学号、邮箱、地址或聊天记录。
- 不得出现本机用户名、绝对路径、浏览器账号、书签栏、扩展信息或通知内容。
- 截图前关闭开发者工具、密码管理器提示和无关标签页。
- 演示数据统一使用虚构主题；生成结果只作为策划示例，不表示真实采访或事实结论。
