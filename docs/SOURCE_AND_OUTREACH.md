# 采访对象与联系记录

`InterviewSource` 记录公开称呼、私密身份、角色、信息价值、可接触性、可能偏差、状态、替代信源、预约、归因和同意。

## 私密字段

真实身份、电话、邮箱、微信和私密备注只保存在本地项目中，公开演示、脱敏分享与课程提交会移除。匿名来源只导出 `publicLabel`。

## 联系模板

内置学生、教师、专家、学校管理者、商业机构和敏感对象模板，包含：记者身份、联系原因、主题、采访目的、预计时长、方式、录音计划、使用方式、匿名选项和回信渠道。

模板只生成可编辑草稿；不自动发送、不冒充用户、不催促或施压。用户在站外完成联系后，手工记录渠道、时间与回应状态。

## 状态机

`identified → contact_drafted → contacted → responded/scheduled → interviewed → follow_up_needed/completed`。拒绝、无法联系和放弃是显式状态；不允许从“已识别”直接跳到“已采访”。
