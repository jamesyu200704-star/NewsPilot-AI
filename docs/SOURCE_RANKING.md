# 来源分类与等级

## 来源类型

P1 区分原始文件、正式声明、官方数据、学术来源、新闻报道、采访材料、用户材料、社交帖子、商业内容、转载和未知类型。

## 等级

- A：适用范围明确的政策原文、原始数据、法院文件、正式报告、当事机构声明或可验证的直接采访材料。
- B：有独立采集方法的可靠报道、同行评审研究或专业机构调查。
- C：转载、商业宣传、来源不透明汇总或没有原始材料的评论。
- `lead_only`：社交帖、匿名论坛、截图和未核实爆料。
- `unrated`：尚不能判断的材料；用户上传默认属于此级。

“官网”不自动等于 A 级。宣传材料只证明机构公开宣传过什么，不能证明宣传效果。媒体名称也不自动决定具体文章等级。

规则会给出初始分类；用户可以修改类型和等级，但必须填写理由。每次自动分类和用户修改都会写入 `classificationHistory`。
