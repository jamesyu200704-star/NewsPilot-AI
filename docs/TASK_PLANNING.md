# 任务与截止期倒排

`ExecutionPlanner` 根据 `deadline / publishAt` 反向安排：确认角度、案头研究、联系信源、准备提纲、采访、整理材料、关闭证据缺口、建立提纲、作业检查和导出。

## 时间规则

- 少于 48 小时：压缩为最小可交付路径，今日优先联系关键对象、确认角度和关键核验。
- 3—7 天：按研究、联系、采访、核验和提交顺序倒排。
- 超过 7 天：保留更多研究和复核缓冲。

## 可编辑字段

任务名称、状态、优先级、截止时间、预计分钟数、人工阻塞原因和完成条件均可修改；卡片可拖动排序。依赖未完成时会显示 blocker。

## 完成条件

`done` 只代表用户确认已达到卡片中的完成条件。采访任务还受采访完成门槛约束；导出任务还受隐私确认和作业阻断项约束。
