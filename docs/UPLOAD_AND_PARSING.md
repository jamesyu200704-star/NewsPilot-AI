# 材料上传与解析

支持 TXT、Markdown、CSV、JSON、PDF 文本层和 DOCX。文件在浏览器本地解析并写入浏览器本地项目，不默认发送到后端或第三方模型。

默认限制：单文件 10 MB、单项目 50 MB；同时限制 DOCX 解压后大小。解析器校验扩展名、MIME 和 PDF/DOCX 文件头，拒绝伪装的可执行文件、DOCX 宏、ActiveX、嵌入对象、自定义 UI 和压缩炸弹。

PDF 只读取文本层，不实现 OCR。扫描版会提示：

> 该文件可能是扫描版，当前版本无法识别图片文字，请上传可复制文本的版本或手动粘贴内容。

上传材料自动成为 `user_material / unrated`，不会自动获得 A 级。文本被切成最多 20 个短证据片段，初始关系为 `context`、状态未确认；用户需要选择主张、关系和直接性后确认。

浏览器实际读取 `VITE_UPLOAD_MAX_FILE_MB` 与 `VITE_UPLOAD_MAX_PROJECT_MB`，默认分别为 10 MB 与 50 MB；这些公开构建变量只允许填写非敏感数字。服务端保留不带 `VITE_` 的同名限制，供未来受控上传接口复用。若未来增加后端上传，必须默认不持久化并立即删除临时文件。
