# 交叉验证规则

核实状态由规则引擎计算，模型和 UI 都不能直接宣布“已核实”。

## Verified

主张必须先由用户确认为可按事实核查的 `fact/statistic/allegation`，且没有可信冲突，并满足以下任一条件：

- 一个直接、范围一致的 A 级原始来源；或
- 两个不同独立来源组的 A/B 级高质量二手来源。

## Partially verified

只有一份可靠二手来源，或可靠材料的时间、地域、样本和主张范围尚未完全一致。

## Unverified

没有证据、只有搜索摘要、社交线索、C 级转载/商业内容、未定级用户材料、不可访问页面，或主张仍是未确认的假设。

## Conflicted

可信 A/B 来源同时提供支持和反驳片段。系统保留冲突并给出核对定义、时间、地域、样本、规则层级及采访双方的下一步任务，不按数量投票。

社交媒体、转载、商业内容和用户拒绝的来源不参与可信冲突判定。观点必须归因；没有真实采访时不得生成引语。
