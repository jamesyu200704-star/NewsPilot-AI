# 新闻编辑模块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让语言润色、结构修改和新闻评论成为三个边界清楚、输出不同的新闻编辑任务。

**Architecture:** 保留现有 `NewsEditAction` 请求结构，在提示词构建层按 action 生成独立规则，在 MVP 组件中使用同一份动作配置驱动说明、输入和结果文案。服务端继续用现有结构化 JSON 和事实保护校验。

**Tech Stack:** TypeScript、React、Node.js test runner、Vitest、Ollama
