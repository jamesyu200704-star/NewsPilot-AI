# NewsPilot v1.1.0 Beta 1 发布说明

## NewsPilot Public Beta

NewsPilot 是面向新闻传播专业学生和校园媒体的报道工作台。它把课程要求或校园线索整理为报道判断、采访路径、证据缺口和可执行任务，不自动代写新闻稿。

## 当前版本已完成

- 报道任务与课程要求解析；
- 新闻问题、新闻价值与报道策略设计；
- Search、证据台账、来源去重与交叉验证；
- 采访对象、采访提纲与采访执行；
- 逐字稿、引语核对和证据闭环；
- 报道大纲、作业自查与多格式脱敏导出；
- 本地用户研究与匿名盲评工具。

## 当前验证状态

- 真实参与者：0；
- 真实研究场次：0；
- 真实盲评结果：0。

因此当前版本仍为 Beta，不应视为已经过充分验证的正式稳定版本。仓库历史中的 `v1.0.0` 也不构成真实用户验证证据。

## 安全边界

NewsPilot：

- 不替代真实采访；
- 不自动证明事实；
- 不生成虚构采访或虚构引语；
- 不允许未确认引语进入正式导出；
- 不允许 off the record 内容进入公开材料；
- 不默认记录或上传用户研究数据。

## 已知限制

- 尚未完成真实新闻学生测试；
- 本地 Ollama / Qwen、SearXNG 和 Local Whisper 需要独立配置；
- Vercel 公共 Demo 只提供安全的 Mock / Manual 能力；
- AI 输出和搜索线索仍需记者人工核验；
- 尚未完成真实手机硬件与完整读屏环境复测。

## 隐私与升级

项目数据默认保存在当前浏览器。公开仓库不包含真实采访材料、联系方式、逐字稿、音频、私人课程材料或真实研究数据。数据版本 1/2 的本地项目会迁移到版本 3，升级前建议先导出备份。
