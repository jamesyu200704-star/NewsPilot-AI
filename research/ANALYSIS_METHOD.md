# 分析方法

默认只分析 `synthetic=false`。模拟数据单独筛选，绝不合并。报告同时给出分子、分母、样本量和缺失字段，不只给百分比。

核心指标：首个可执行方案中位数 ≤10 分钟；任务完成率 ≥80%；下一步清晰度 ≥70%；采访对象采用率 ≥60%；问题采用率 ≥50%；重大重写率 ≤30%。样本为 0 时显示“验证不足”，不显示 0% 或 100%。

问题按严重度、频率和影响排序，合并重复问题；Critical 和 High 优先。单个“想要”不直接变成功能需求。第二轮必须显示前后样本量；每轮样本不足时只输出“样本不足”。

安全底线以真实观察事件计数；没有样本只能写“未观察/验证不足”，不能声称实际发生率为 0。
