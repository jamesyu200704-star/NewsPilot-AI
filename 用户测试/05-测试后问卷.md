# 测试后问卷

除开放题外，使用 1—5 分：1 表示完全不同意，5 表示完全同意。不得预填。

1. 我理解系统为什么给出 GO / REVISE / HOLD / DROP 判断。
2. 推荐的新闻问题比我的原始主题更具体。
3. 推荐角度适合当前作业或刊发任务。
4. 推荐采访对象在现实中可以接触。
5. 采访问题可以直接使用或只需轻微修改。
6. 我能区分已知事实、工作假设和待核实内容。
7. 下一步行动计划能帮助我立即开始工作。
8. 我清楚内容只保存在当前设备和浏览器中。
9. 我愿意在下一次采访作业或校园报道中再次使用 NewsPilot。

开放题：

- 哪一部分最有帮助？为什么？
- 哪一部分最难理解或最不可信？
- 你采用了哪个角度？如果没有采用，原因是什么？
- 哪些采访对象无法接触？你会怎样替换？
- 你修改了哪些采访问题？
- 估计最终方案需要修改多少：0—20% / 21—40% / 41—60% / 61—80% / 81—100%。
- 如果只能改一件事，你希望改什么？
