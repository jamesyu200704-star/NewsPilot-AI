# NewsPilot P0 用户测试材料

本目录用于组织真实用户测试。当前状态：**尚未开展，不包含任何真实测试结果**。

建议招募至少 5 名新闻传播专业学生、2 名校园媒体成员，并覆盖人物特稿、校园现象调查、校园政策观察三类任务。主持人应先阅读招募与伦理说明，再按脚本执行；观察表、问卷和反馈表只能记录真实参与者数据。

文件说明：

- `01-招募标准.md`：筛选条件、样本配额与伦理边界。
- `02-测试任务.md`：三类可替换测试任务和完成标准。
- `03-主持人脚本.md`：开场、任务指令、追问与结束语。
- `04-观察记录表.csv`：逐任务观察指标；只有表头，没有虚构记录。
- `05-测试后问卷.md`：理解、可执行性、修改量与再次使用意愿。
- `06-匿名结果模板.json`：版本化空结果文件。
- `07-用户反馈录入格式.csv`：问题与建议的结构化录入格式。
- `08-人工盲评说明.md`：NewsPilot、通用模型和学生方案的匿名对照流程。

公开汇报时必须同时说明样本数、招募方式、测试日期、任务版本和限制。自动化测试与 `eval:campus` 只能说明程序结构和规则约束正常，不能替代真实新闻质量评测。
